# Self-hosted fonts

Manrope and Cormorant Garamond from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Distributed under the included SIL Open Font License 1.1 files. Fonts are served by this site; no runtime connection to Google Fonts is made.

Manrope is converted to WOFF2. Cormorant Garamond normal and italic are converted to WOFF2 and subset to Latin, extended Latin, Cyrillic, combining marks and common punctuation/currency/arrows. Other scripts use the browser's fallback fonts. Manrope retains variable weights; Cormorant Garamond uses a static 500 instance to keep downloads small. Original copyright/licensing metadata is retained.

The admin font library also includes Onest, Montserrat (normal/italic), and Literata (normal/italic), from the respective `ofl/onest`, `ofl/montserrat`, and `ofl/literata` directories of https://github.com/google/fonts. Each has its original OFL license alongside the binaries. These are WOFF2 subsets retaining Latin, Cyrillic, combining marks and common punctuation; Onest and Montserrat retain variable weight axes; Literata uses static weight 500 and optical size 48. Onest has no supplied italic face and uses browser oblique when italic is requested.
