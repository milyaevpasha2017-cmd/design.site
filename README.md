# Epiphany Interior

Адаптивный сайт авторской практики дизайнера интерьеров. Статический HTML, CSS и JavaScript без зависимостей и сборки.

## Запуск

```sh
cd /workspace/design.site
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт через доступный в вашей среде способ просмотра. Проверка HTTP: `curl --fail http://127.0.0.1:8000/`.

## Перед публикацией

- Заменить концепции на реальные проекты, фотографии и описания. Текущая иллюстрация сгенерирована ИИ, три карточки показывают направления на её основе.
- Добавить реальные контакты дизайнера.
- Подключить доставку заявок через сервер или сервис форм и настроить необходимые условия обработки персональных данных. Сейчас форма только готовит текст для копирования: данные не отправляются и не сохраняются.
- Уточнить состав услуг и добавить реальные цены, если они должны быть публичными.

Для размещения достаточно любого хостинга статических сайтов. Секреты и серверные зависимости сейчас не нужны.
