# Epiphany Interior

Сайт-портфолио с Decap CMS: проекты и фотогалереи, видео ВК, услуги, этапы работы и контакты. Сохраняет исходный дизайн и работает без сборки.

## Админка

**Пошаговая инструкция для владельца: [docs/ADMIN-SETUP.md](docs/ADMIN-SETUP.md).**

Адрес: https://milyaevpasha2017-cmd.github.io/design.site/admin/

До подключения OAuth панель показывает инструкцию. Требуется один раз развернуть `auth-worker/src/worker.mjs` в Cloudflare Workers, создать GitHub OAuth App, задать секрет в Cloudflare и указать публичный адрес Worker в `admin/settings.json`. Реальный вход и запись нужно проверить после этой настройки.

Контент хранится в `content/site.json`, изображения — в `assets/`. Decap CMS 3.17.1 поставляется локально в `admin/vendor/` с лицензионными уведомлениями. Сам сайт не зависит от стороннего CDN.

## Публикация

В GitHub **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует только файлы сайта, без тестов, документации и кода Worker. После сохранения из CMS дождитесь успешного workflow, прежде чем проверять обновления.

## Локальный запуск

```sh
cd /workspace/design.site
python3 -m http.server 8000 --bind 0.0.0.0
```

```sh
node --test tests/*.test.mjs
```

Сайт не требует зависимостей и секретов. Для реальной авторизации админки нужен настроенный HTTPS-сервис OAuth; локальный HTTP-сервер его не заменяет. `auth-worker/wrangler.toml` — дополнительная конфигурация развёртывания Worker через Wrangler CLI.

## Возможности и ограничения

- Изменение текстов, заголовков, проектов, изображений, услуг, этапов и контактов через CMS.
- VK Видео: ссылки `videoOWNER_ID`, `video_ext.php` и экспортированный iframe. Плеер загружается только после нажатия. Ограничения ВК на доступ/встраивание сохраняются.
- Ссылки YouTube, Telegram, группа ВК и email. Пустые поля скрываются.
- Форма готовит обращение локально, позволяет скопировать текст и при указанном email открыть почтовую программу. Автоматической отправки и базы заявок нет.
- Текущие проекты и иллюстрация — явно обозначенные демонстрационные концепции. Перед продвижением добавьте настоящие работы и контакты.
- Загружать персональные данные клиентов или секреты в публичный репозиторий нельзя.

Свой домен необязателен. При его подключении обновите origin у Worker, ссылки сайта в CMS и Homepage URL в OAuth App — подробнее в инструкции.
