# Яндекс Метрика

Счётчик: `113965901`. Публичные страницы подключают `metrika.js`; админка и API не подключают счётчик. Параметры сохранены из предоставленного кода: Вебвизор, карта кликов, ссылки, точный показатель отказов, `dataLayer`.

Имя, контакт и сообщение формы помечены `ym-disable-keys`, чтобы Вебвизор не записывал их содержимое. В событие не передаются данные заявки или её UUID.

В интерфейсе Метрики создайте цель «Заявка отправлена», тип JavaScript-событие (целевое событие), идентификатор `lead_submitted`. Событие вызывается после успешного ответа `/api/leads` с совпадающим UUID; ошибки и нажатие кнопки его не вызывают. Недоступность Метрики не мешает приёму заявки.

Счётчик подключён как внешний локальный скрипт, загружающий официальный асинхронный тег. Публичные ответы не используют CSP админки; политика админки не ослаблена.
