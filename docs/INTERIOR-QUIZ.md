# Интерьерный квиз

Адрес: `/quiz/`, заметный блок сразу после первого экрана главной.
Пять шагов: тип помещения, визуальное настроение, несколько приоритетов, этап проекта, срок начала и необязательная площадь.

Три оригинальные SVG-иллюстрации показывают настроение, не выдаются за фотографии реализованных проектов. Результат открыт до ввода контактов. Правила используют выбранное настроение, приоритеты и этап; это ориентир для разговора, без оценки личности, обещания точной стоимости или доступности дизайнера.

Конфигурация: `site-worker/src/quiz.json`; правила: `quiz-model.mjs`; интерфейс: `quiz.js`. Статическая и живая версии проверяются на совпадение HTML. Предпочтения остаются в памяти страницы, не сохраняются в браузерное хранилище. Перезагрузка начинает квиз заново.

Отправка необязательна. После результата показывается существующая форма с отдельной неотмеченной галочкой согласия. В `message` передаётся текстовая сводка всех ответов, направление, рекомендуемый формат и комментарий клиента (до 1500 символов). Используется существующий `/api/leads`: приватная SQLite-база, проверка согласия, лимиты, UUID и повтор без дублирования, очередь Telegram. Telegram получает только номер заявки и ссылку на закрытую админку. SMTP остаётся отключённым до отдельной настройки.

Метрика 113965901: `quiz_started` — первый выбор; `quiz_completed` — первый показ результата; `quiz_lead_submitted` — только подтверждённое сервером принятие заявки из квиза. Существующая `lead_submitted` также срабатывает. Каждый этап считается один раз на загрузку страницы; содержимое ответов/контактов в параметры целей не передаётся. Аналитика работает только после согласия. Для отчётов создайте три цели типа «JavaScript-событие» с этими идентификаторами в кабинете Метрики.
