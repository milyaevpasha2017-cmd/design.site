# Главная: меньше повторов, больше визуального ритма

С главной убраны подробные описания четырёх услуг, повторный абзац «Обо мне» и подробный трёхэтапный процесс. Исходные данные CMS не удалены: полные услуги, процесс и подход остаются на внутренних страницах. Разбор решений и текст входа в квиз сокращены.

`motion.js` работает только на главной. Портфолио при JS превращается в нативную горизонтальную scroll-snap галерею: свайп/трекпад, кнопки «Назад»/«Далее», живой счётчик, состояния крайних кнопок. Вертикальные wheel-события не перехватываются. Без JS остаётся обычная сетка ссылок.

Кадры галереи получают смещение до 12 px в обе стороны внутри обрезанного контейнера. Обработка через requestAnimationFrame, только для видимых кадров. Заголовки появляются однократно без исходного скрытия. Декоративные изображения квиза делают короткое движение при входе в экран; бесконечного автоматического движения нет. Prefers-reduced-motion отключает анимации, дрейф и плавное перелистывание, функции остаются доступны.

Формы, квиз, аналитические цели, серверные заявки и очередь Telegram не изменялись.
