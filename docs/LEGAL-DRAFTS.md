## Проект политики конфиденциальности

1. Сайт `epiphany-int.ru` представляет портфолио Epiphany Interior. Ответственный за работу с обращениями — Миляев Павел Сергеевич, связь: `epifanovaps@yandex.ru`.
2. При просмотре хостинг Cloudflare получает технические сведения, необходимые для доставки страниц: в частности IP-адрес, параметры запроса и браузера. Настройки и сроки журналирования у провайдера требуется подтвердить. Нельзя писать, что при просмотре «никакие данные не обрабатываются».
3. Форма обращения формирует текст в браузере. Нажатие «Подготовить обращение» не отправляет имя, контакт и сообщение на сервер сайта. Кнопка почты открывает почтовую программу; сообщение отправляет сам посетитель. При копировании текст может попасть в системный буфер обмена. Код не сохраняет поля в localStorage и не создаёт базу заявок.
4. При переходе по контактным ссылкам и отправке сообщения данные обрабатывают выбранные сервисы — Telegram, ВКонтакте, YouTube или почтовые провайдеры. Обращения поступают оператору вне сайта; сроки их хранения и основания обработки `[подтвердить]`.
5. Плеер ВКонтакте загружается только после нажатия на кнопку просмотра. После этого браузер связывается с ВКонтакте, который обрабатывает сведения по своим правилам. Ссылки на внешние сервисы сами по себе не означают, что оператор контролирует их обработку.
6. В коде нет аналитики и рекламных пикселей. Владелец также подтвердил, что не подключал их вне кода. При смене хостинга проверить отсутствие автоматического подключения и актуализировать документ.
7. Доступ к панели предназначен администратору. Пароль проверяется на сервере по солёному хешу. Для входа используется защищённая HttpOnly cookie со сроком до восьми часов. Сервер хранит сведения о сессии и ограничивает попытки входа по хешу IP; запись ограничения действует около минуты и удаляется таймером очистки. Журналы Cloudflare — отдельный, не проверенный этим кодом процесс.
8. Тексты и фотографии, добавленные через панель, записываются в общедоступный репозиторий GitHub и могут публиковаться на сайте. История Git сохраняет прошлые версии. Снятие флага публикации не делает исходные файлы или адреса фотографий приватными. Удаление проекта из текущей версии не удаляет его историю, файлы фотографий, чужие копии и кеши. Приложение автоматически не очищает метаданные загруженных изображений.
9. Для вопросов об обработке и запросов на изменение/удаление сведений: `epifanovaps@yandex.ru`. Порядок и сроки ответа `[заполнить после уточнения оператора и применимого права]`. Нельзя обещать мгновенное окончательное удаление всех копий публичных файлов.
10. У посетителей нет учётных записей, платежей, напоминаний и профилей. Если эти функции появятся, политику потребуется пересмотреть.
