Подготовка пароля администратора

Откройте этот файл на своём компьютере. Он работает без сети: пароль обрабатывается только в браузере. На сервер вы перенесёте хеш, а не сам пароль.

Сохраните выбранный пароль в своём менеджере паролей. Не публикуйте пароль или хеш в репозитории и не присылайте их в чат. Сам этот файл не сохраняет введённые значения.
