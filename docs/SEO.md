# Поисковая доступность Epiphany Interior

Проверка 31 октября 2026 года. Основной домен: https://epiphany-int.ru/.

## Исправлено

- `/robots.txt` раньше возвращал 404. Теперь доступен без авторизации, содержит адрес актуального sitemap и исключает API/метаданные выпуска. CSS, JavaScript, изображения и публичные страницы доступны роботам. Страница входа доступна для чтения `noindex`; robots не мешает прочитать этот запрет. Защита админки по-прежнему обеспечивается авторизацией.
- Пустая страница видео получает `noindex,follow` и исключается из sitemap. При публикации видео через CMS эти ограничения снимаются автоматически, в том числе без пересборки.
- Страница ошибки возвращает 404, `noindex` и больше не объявляет главную своим canonical. Ответ при ошибке публикации остаётся 503 с Retry-After и noindex.
- Админка и API дополнительно получают X-Robots-Tag: noindex, nofollow. Метатеги noindex в HTML админки уже были и сохранены.
- В title и description уточнены тематика и реальные услуги. Заголовки концепций прямо отличают их от реализованных проектов. На главной добавлено короткое пояснение специализации.
- Добавлена серверная JSON-LD-разметка Organization, WebSite, WebPage/AboutPage/ContactPage/CollectionPage и BreadcrumbList. Контакты берутся из текущего содержимого сайта; вымышленные адреса, рейтинги, отзывы и реквизиты не добавлялись.
- Для превью ссылок добавлены название сайта, изображение и тип карточки Twitter.
- GitHub Pages остаётся доступным, но canonical и sitemap его сборки теперь указывают основной домен epiphany-int.ru. Пути ресурсов зеркала сохранены. Это указание для поисковых систем, а не гарантия выбора canonical.

## Уже работает

Основной контент, ссылки, изображения и метаданные присутствуют в исходном серверном HTML. На страницах по одному H1. Canonical очищен от UTM/параметров отладки. Адреса без завершающего слеша и с index.html перенаправляются 301. Неизвестные страницы возвращают 404. Sitemap обновляется вместе с опубликованными проектами.

## Что зависит от реального контента и внешних кабинетов

В портфолио сейчас три концепции с одной общей иллюстрацией и короткими описаниями. Они честно помечены как концепции. Для содержательной ценности нужны настоящие разные изображения, задача, решения и материалы каждого проекта; придуманные объекты или результаты не добавлялись. География, имя дизайнера и прочие сведения должны быть подтверждены владельцем, а не угаданы.

Для следующего шага стоит подтвердить сайт в Яндекс Вебмастере и Google Search Console, отправить https://epiphany-int.ru/sitemap.xml и проверить главную/услуги инструментами просмотра URL. Эти кабинеты и фактическое включение страниц в поиск в рамках изменения не проверялись. Разметка не гарантирует расширенного сниппета или позиции.

## Проверки

Автотесты сопоставляют статический и динамический HTML. Отдельно проверяются hierarchy/canonical/JSON-LD, экранирование, noindex ошибок и пустого видео, автоматическое включение видео после публикации, доступность robots без входа, запреты индексации админки/API, canonical зеркала и доступность его ресурсов.
