# Проверки изменений epiphany-int.ru

Выполняйте при каждой правке сайта, в том числе контента, интерфейса и админки.

1. Проверьте инвентарь дизайна (`python3 scripts/design-inventory.py --check`), тесты JavaScript (`node --test tests/*.test.mjs`) и Python (`python3 -m unittest discover -s tests -p 'test_*.py'`).
2. Проверьте оптимизацию изображений, сборку, аудит секретов и упаковку релиза. Эти шаги выполняет workflow **Publish Timeweb site**.
3. После публикации подтвердите версию через `/deployment.json`. Проверьте `/healthz`, главную и страницу входа в админку.
4. Проверьте страницы из `sitemap.xml`: HTTP 200, один H1, канонический URL. Проверьте `robots.txt` и файлы подтверждения Яндекса и Google.
5. В браузере проверьте изменённые страницы и сценарии на компьютерной и мобильной ширине. Для изменений админки проверяйте сохранение и результат на публичном сайте в тестовой среде или на подготовленных тестовых данных.
6. В отчёте укажите результаты и проверки, для которых не было доступа или подходящего устройства.
